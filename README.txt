ONDE ESTÁ O SR. ALFABETO? — V1 JOGÁVEL

Abra index.html em um servidor web estático. Para teste local no Mac:
  cd sr-alfabeto-v1
  python3 -m http.server 8080
Depois acesse http://localhost:8080 no navegador.

Fluxo: abertura > 5 fases > vídeo intermediário > 5 fases > celebração > esteira > vídeo final > encerramento.
Sem login, banco de dados ou coleta de dados.
